# Ideias de Design - HypeCerto

## Abordagem Selecionada: Modern Tech Dashboard com Accent Roxo

### Design Movement
**Neomorphism Digital** - Fusão de elementos modernos com profundidade sutil, inspirado em interfaces de SaaS contemporâneas.

### Core Principles
1. **Hierarquia Clara**: Uso estratégico de roxo (#6D28D9) como cor primária para CTAs e elementos críticos
2. **Espaço Negativo Generoso**: Layouts respirados que não sobrecarregam o usuário
3. **Micro-interações Fluidas**: Transições suaves entre estados (hover, focus, active)
4. **Acessibilidade Primeiro**: Contraste adequado, navegação clara, feedback visual consistente

### Color Philosophy
- **Primária**: Roxo (#6D28D9) - Energia, confiança, tecnologia
- **Secundária**: Branco (#FFFFFF) - Clareza, espaço
- **Terciária**: Cinza Escuro (#1F2937) - Profundidade, fundo
- **Neutro**: Cinza Médio (#6B7280) - Texto secundário
- **Accent**: Roxo Claro (#A78BFA) - Hover states, elementos secundários

### Layout Paradigm
- **Sidebar Esquerda**: Navegação persistente com ícones + texto
- **Header Superior**: Logo, navegação principal, user menu
- **Conteúdo Central**: Grid responsivo com cards e gráficos
- **Assimétrico**: Sidebar + main content (não centralizado)

### Signature Elements
1. **Botões Roxos Arredondados**: CTA principal com hover effect
2. **Cards com Sombra Sutil**: Profundidade sem peso visual
3. **Ícones Lucide**: Consistência visual em toda a interface
4. **Dividers Roxos Suaves**: Separação de seções com cor de marca

### Interaction Philosophy
- Hover: Mudança de cor + elevação leve (shadow)
- Click: Feedback tátil via cor + transição
- Focus: Ring roxo claro ao redor de inputs
- Disabled: Opacidade 50% + cursor not-allowed

### Animation
- **Transições**: 200ms ease-in-out para todas as mudanças de estado
- **Entrada de Página**: Fade-in suave (300ms)
- **Modais**: Slide-up com backdrop blur
- **Hover**: Scale 1.02 + shadow increase

### Typography System
- **Display**: Poppins Bold (24px+) - Títulos principais
- **Heading**: Poppins SemiBold (18px-22px) - Seções
- **Body**: Inter Regular (14px-16px) - Conteúdo
- **Small**: Inter Regular (12px) - Labels, hints
- **Mono**: Fira Code (11px) - Códigos, dados técnicos
